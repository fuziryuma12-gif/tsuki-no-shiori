# 月のしおり

月に一度、好きなタイミングで、その月に読んだ本と観た映画をふり返って記録するアプリ。
記録が溜まってきたら、Gemini がその傾向から次の一冊・一本を選んでくれる。

```
[ スマホのホーム画面 ]   [ PCのブラウザ ]
        └────── 同じアカウント ──────┘
                    ↓  PWA（GitHub Pages などの静的ホスティング）
   index.html / app.js / styles.css / sw.js / manifest.json
                    ↓  POST（text/plain）＋ セッショントークン
        [ GAS ウェブアプリ ]  ← Gemini APIキーはここに置く
                    ↓
        [ スプレッドシート ]
   Users / Sessions / LoginCodes / Shelves / Memberships / Entries / Recs
```

---

## 作りの要点

**なぜフロントとバックを分けているか**

GAS の `HtmlService` が返す画面はサンドボックス iframe（`googleusercontent.com`）の中で動きます。
そのため Service Worker の登録と `manifest.json` の読み込みが通らず、**GAS だけでは PWA が成立しません。**
見た目は静的ホスティングに置き、データと AI は GAS、という分け方にしています。

**ログイン**

メールアドレスに6桁のコードを送るだけの、パスワードのない方式です。
ログインに成功すると GAS がセッショントークンを発行し、端末の `localStorage` に入ります。
スマホでもPCでも、同じメールでログインすれば同じ本棚が並びます。

- コードは10分で失効。入力を5回間違えるとそのコードは無効になります
- コードもトークンも、平文ではなく SHA-256 のハッシュでシートに保存されます
- セッションは60日。使っていれば静かに延長されます
- 同じメール宛は1時間に5通まで、全体で1日60通まで（メール送信枠を使い切らないため）

**人と本棚**

`Users` と `Shelves` は別物で、`Memberships` が両者をつなぎます。
1人が複数の本棚を持て、友人の本棚にも同時に参加できます。上部の本棚名をタップすると切り替わります。
記録を直したり消したりできるのは、それを書いた本人だけです。

## 手順

### 1. Apps Script を用意する

1. <https://script.google.com/> で新しいプロジェクトを作る
2. `gas/Code.gs` の中身を、既定の `コード.gs` に丸ごと貼り替える
3. 左の歯車（プロジェクトの設定）→ **スクリプト プロパティ** に追加

   | プロパティ | 値 |
   |---|---|
   | `GEMINI_API_KEY` | Google AI Studio で発行したキー |
   | `APP_URL` | 公開したPWAのURL。ログインメールに載ります（手順3のあとで可） |
   | `GEMINI_MODEL` | 省略可。既定は `gemini-2.5-flash` |

4. 関数選択から `setup` を実行
   → シートが7枚できます。`HASH_PEPPER` も自動生成されます（**以後この値は変えないでください。変えると全員ログアウトになります**）
5. `testGemini` を実行 →「接続できました」がログに出るか確認
6. `testMail` を実行 → 自分宛にコードのメールが届くか確認

> Gemini のキーを、以前作られたフィットネスボットや採用チャットボットと使い回すと日次上限を取り合います。
> このアプリは月に数回しか叩かないので影響は小さいはずですが、切り分けが面倒なら専用のキーを分けるのが楽です。

**掃除のトリガー（任意）**
「トリガー」→ `cleanupExpired` を日付ベースで1日1回。期限切れのコードとセッションが消えます。

### 2. ウェブアプリとしてデプロイする

「デプロイ」→「新しいデプロイ」→ 種類は **ウェブアプリ**

| 項目 | 設定 |
|---|---|
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **全員** |

出てくる `https://script.google.com/macros/s/.../exec` を控えます。

> 「全員」にしないと別ドメインの静的サイトから呼べません。
> 誰でも API は叩けますが、**中身に触れるのはログインしてトークンを持っている人だけ**です。

### 3. フロントを置く

`frontend/` の中身をそのまま公開すれば動きます。ビルドは不要です。

```bash
cd frontend
git init && git add . && git commit -m "月のしおり"
git branch -M main
git remote add origin git@github.com:<あなた>/tsuki-no-shiori.git
git push -u origin main
```

Settings → Pages → Source を `main` / `/ (root)` にすると
`https://<あなた>.github.io/tsuki-no-shiori/` で開きます。

> HTTPS が Service Worker の条件です。GitHub Pages / Netlify / Cloudflare Pages はどれも満たします。
> 手元で試すなら `python3 -m http.server` で `http://localhost` にすれば、localhost は例外扱いで動きます。

公開できたら、Apps Script の `APP_URL` にそのURLを入れておいてください。

### 4. 使いはじめる

1. 公開URLをスマホで開く
2. 右上の歯車、または画面下の「接続先の設定」から `/exec` URL を貼って保存
3. メールアドレスを入れる → 届いた6桁を入れる → 呼び名と本棚の名前を決める
4. ブラウザのメニューから「ホーム画面に追加」

PCでも同じURLを開き、同じメールでログインすれば、同じ本棚が出てきます。
**URLの登録だけは端末ごとに1回必要です**（ログイン情報とは別に、端末に保存しているため）。

## 使い方

**記録する**
下のバーの「＋ 記録する」。本と映画で「著者／監督」「読み終えた月／観た月」のラベルが切り替わります。
**ひとことは AI が読みます。** 一行でも書いてあると、おすすめの精度がはっきり変わります。

**ふり返る**
「月をさかのぼる」の帯から月を選ぶと、その月だけの一覧になります。記録がある月は濃いピンクです。

**おすすめを聞く**
記録（最新60件）と、任意で「いまの気分」を渡して Gemini に5件選ばせます。選んだ理由が必ず付きます。
共同の本棚では「本棚ぜんぶ／自分の記録だけ」を選べます。

**共有する**

| リンク | 形 | できること |
|---|---|---|
| 招待リンク `#/join/<本棚ID>/<招待キー>` | 本棚に参加 | ログインしたうえで読み書きできる |
| 公開リンク `#/s/<本棚ID>` | 読むだけ | ログイン不要。「公開する」に切り替えたときだけ有効 |

おすすめのカードは1件ずつ、または5件まとめて共有できます。
スマホでは OS の共有シート（LINE など）が開き、PC では文章がクリップボードに入ります。

## 割り切っていること

正直に書いておきます。

- **メールを受け取れる人は、そのアカウントに入れます。** メールボックスが実質の鍵です。二要素認証はありません
- **招待リンクを持っている人は、ログインすれば本棚に参加できます。** SNSに貼らないでください。作り直したいときは `Shelves` シートの `inviteKey` を手で書き換えれば、古いリンクは失効します
- メンバーを後から外す画面はまだありません。`Memberships` シートの行を消せば外れます
- 記録の読み書きはオフラインではできません。Service Worker は**アプリの見た目だけ**をキャッシュしています。古い一覧を見せるより、つながらないと分かる方がよいと考えました
- Gemini は実在しない本を挙げることがあります。プロンプトで抑えていますが、ゼロにはなりません
- ログインメールは**あなたのGoogleアカウントのアドレスから**届きます。迷惑メールに入ることがあるので、友人には先に伝えておくと親切です
- 記録が数千件を超えると GAS の読み込みが重くなります。個人＋友人数名の規模を想定した作りです

## API

すべて `POST` / `Content-Type: text/plain` / ボディは `{"action": "...", ...}`。

| action | 要トークン | 内容 |
|---|:--:|---|
| `requestCode` | | メールに6桁コードを送る |
| `verifyCode` | | コードを照合し、トークンを発行 |
| `me` | ✓ | 自分と、所属する本棚の一覧 |
| `setProfile` | ✓ | 呼び名を変える |
| `logout` | ✓ | この端末のセッションを消す |
| `createShelf` / `joinShelf` / `leaveShelf` / `renameShelf` | ✓ | 本棚の操作 |
| `getShelf` | △ | 中身を取る。公開中ならトークンなしでも読める |
| `setPublic` | ✓ | 読むだけリンクの公開切り替え |
| `addEntry` / `updateEntry` / `deleteEntry` | ✓ | 記録。直せるのは書いた本人だけ |
| `recommend` | ✓ | Gemini におすすめを作らせる |

トークン切れは `{"ok": false, "code": "AUTH"}` を返し、フロントは自動でログイン画面に戻ります。

## ファイル

```
frontend/
  index.html            画面の骨組み
  styles.css            bento と配色（--blush / --paper / --rouge …）
  app.js                状態・描画・API 呼び出し
  manifest.json         PWA の定義
  sw.js                 Service Worker（見た目だけキャッシュ）
  icons/                アイコン4種（maskable 含む）
gas/
  Code.gs               ログイン・シート操作・Gemini 呼び出し
```

配色とタイポは `styles.css` の `:root` に集めてあります。
ベビーピンクを地に、白いカードを載せる構成です。通しモチーフは**しおり**で、
ロゴ、今月のタイル、月の帯のカード、本棚の一覧が同じ V 字の切り込みを持っています。
色味を変えたいときは `--blush`（地）と `--rouge`（差し色）の2つを触れば全体が動きます。
